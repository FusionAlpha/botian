# Reproduction protocol

## What is reproduced

The release covers the seven active dispersion figures, using the numerical inputs and selection policies of the manuscript. It does not regenerate the high-dimensional speedup tables or run external reference solvers. Literature PDFs, digitized paper curves and MATLAB executables are not required or distributed.

The default command is a fresh calculation:

```sh
python reproduce.py
```

It computes source spectra, applies the case's selector and renders the results. Failure in the numerical path is reported as a failure; frozen data are not substituted. `--mode cached` instead redraws supplied arrays and must not be described as a fresh numerical reproduction. `--mode smoke` checks one midpoint per case (one for each signed-EM half) and does not establish full-scan agreement.

## Case settings

Here `J` is the pole order and `N` the source harmonic cutoff. Refinement probes used by the selector are separate from these source settings. The input files and executable case definitions are authoritative for species parameters, coefficient tables and normalization.

| Case | Source model | J | N | Full scan |
| --- | --- | ---: | ---: | --- |
| `es1d_beam` | Parallel electrostatic BO embedding of the PDRK beam example | 8 | 1 | 50 points, k lambda_De = 0.01 to 0.50 |
| `umeda_ring_beam` | Electromagnetic ring beam | 8 | 8 | 117 points, k lambda_De = 0.01 to 0.30 |
| `signed_em` | Electromagnetic model, both signs of parallel wave number | 8 | 1 | 500 points, k_z c/Omega_ce = -2.50 to -0.01 and 0.01 to 2.50 |
| `hh_ring_beam` | Hermite-Hermite fitted ring beam | 12 | 6 | 117 points, k lambda_De = 0.01 to 0.30 |
| `firehose` | Hermite-Hermite firehose | 24 | 2 | 46 points, k v_A/Omega_ci = 0.05 to 0.50 |
| `muschietti_beam` | High-harmonic electromagnetic beam | 8 | 60 | 131 points, k c/omega_pi = 10.0 to 75.0 |
| `loss_cone_mirror` | Electromagnetic loss-cone mirror | 8 | 3 | 100 points, k_z/k_n = 0.01 to 1.00, fixed k_x/k_n = 0.5 |

`signed_em` solves the positive and negative scans separately; negative wave numbers are not generated by reflecting positive roots. Its configuration is electromagnetic, despite the historical internal case identifier containing `darwin`.

The HH ring-beam inputs contain the printed-fit distribution coefficients used for the manuscript figure. The source uses J = 12; the selection policy uses a forward J = 24 refinement probe. This probe and the forward-refinement legacy policy were chosen during method development, so these results are not a blind holdout evaluation. The historical HH ring-beam source spectrum was computed using MATLAB Runtime; this release uses the native Python implementation with the same bundled coefficients. Native-backend agreement must be assessed numerically, not inferred from that common input.

## Results and provenance

By default, generated files are separated by mode and case under `results/`. Use `--output` to select another destination. Inputs and frozen data are read-only during reproduction.

Frozen arrays contain source-spectrum points and selected points. Their checksums and provenance identify the original numerical artifacts. Cached mode checks these files before plotting. Fresh calculation records the actual scan subset and numerical settings; use the run record to distinguish a complete scan from a smoke or interrupted calculation.

```sh
python reproduce.py --case firehose
python reproduce.py --case firehose --resume
python reproduce.py --mode cached --output results/figure_redraw
```

Resume reuses compatible per-scan results. Changed inputs, code or numerical settings require recomputation rather than treating an old prediction as current.

Keep the entire source tree when moving the release. The supported reference installation is `python -m pip install -r requirements.txt -e .` from the extracted directory. It resolves bundled input paths without the original research workspace. The four direct numerical/plotting dependencies are pinned; Python and platform BLAS can still affect floating-point results. Calculations use one BLAS thread.

## Numerical and visual comparisons

Eigenvalue order is not stable across LAPACK implementations. Compare complex roots as unordered sets with multiplicity, using a stated normalized tolerance. File hashes establish artifact integrity, not bitwise numerical reproducibility across machines. Record Python, NumPy, SciPy, BLAS and thread settings with timing or parity results.

Gray markers show the dynamic BO spectrum after excluding declared auxiliary poles and zero/constraint roots. Colored markers show selected candidates. Track grouping changes only marker appearance; it does not replace, interpolate or add numerical roots. Plot windows can hide roots outside the displayed range.

Agreement with a finite BO spectrum and selection under refinement are distinct from certification against the target kinetic response. Continuous-contour certification additionally requires the error bounds and hypotheses stated in the manuscript. These figure scripts do not assert that every colored point meets those conditions. The mirror and damped-branch examples retain their documented incomplete coverage.

## Verification scope

The automated workflow runs unit tests, all cached redraws and an ES1D midpoint calculation. It deliberately excludes the full 1,061-point recomputation and performance measurements. A successful smoke run establishes that a numerical path executes, not that an entire figure or speedup claim has been independently reproduced.

The original research results remain in the research workspace. This release contains the selected active source and compact provenance, not historical campaigns or manuscript drafts.
